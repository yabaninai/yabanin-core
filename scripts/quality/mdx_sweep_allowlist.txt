# Conventions follow scripts/docs_lang_allowlist.txt: one entry per line,
# content-keyed as <repo-relative-path>:<sha256-of-the-source-line-16hex>.

# MDX005 warning. FATAL findings (MDX000-004: unreadable file, raw '<'

# HTML comment) are NOT allowlistable — fix the file.

# them as JavaScript at build/render (SSR hazard class). Allowlist only
# intentional JSX expressions that belong in the
# public site; prefer code-spanning literal text instead.
#

# site-excluded warnings by design and need no entries).
